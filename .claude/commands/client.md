description: One client's whole card before any conversation - safety alert, consent, files, recent sessions, goals, concerns and file notes. Read this before drafting anything about a client.
---

1. Run `node scripts/cases.mjs client "<name or C-ref>" --json`. If it lists candidates, ask which.
2. If there is a safety alert, it is the first line, word for word.
3. Then: consent state, each file (programme, worker, state, last and next session), the last few sessions, goals with progress, open concerns, the latest file notes.
4. Say the one thing that needs doing, if anything does.
5. Records only. Nothing is ever sent to a client, family or another agency from here.
